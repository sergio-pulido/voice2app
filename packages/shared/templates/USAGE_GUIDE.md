
# 🧭 Usage Guide — App Templates (Vite & Next.js)

This guide explains **how to integrate, run, and customize** the three included templates in automated app generation systems such as **Voice-to-App** or **WalkCoder**.

---

## 1️⃣ Quick Start

```bash
cd templates/<template-name>
npm install
npm run dev          # launches on port 5173
```
Each template contains a `healthz` endpoint or file.  
Check readiness with:

```bash
curl http://localhost:5173/healthz
# → ok
```

---

## 2️⃣ Templates Breakdown

### ⚛️ Vite React Canvas
- Ideal for **games, visual prototypes, or interactive apps**.
- Uses React for UI + Canvas for rendering.
- Healthcheck: `/public/healthz.txt`.
- Ready to integrate with Lingo.dev or AI-generated React components.

### 🧱 Next.js Basic UI
- Ideal for **multi-page apps, dashboards, or API-based projects**.
- Includes API routes (`/api/echo`) and UI cards.
- Fixed port **5173** for both `dev` and `start`.
- Healthcheck via route `/healthz`.

### ⚡ Vanilla TS Canvas
- Ideal for **fast, framework-free canvas demos**.
- No dependencies beyond Vite + TypeScript.
- Easiest to start, smallest cold-start time.
- Best choice for AI-generated games or 2D visualizations.

---

## 3️⃣ Pipeline Integration

In your generation agent or backend:

1. **Select template** based on project intent:
   ```json
   {
     "project": "canvas-game",
     "template": "vite-react-canvas"
   }
   ```
2. **Copy or unzip** into sandbox folder:
   ```bash
   cp -r templates/vite-react-canvas sandbox/job_xxxxxx/
   ```
3. **Inject code** generated by the LLM into `src/` (or `app/` for Next.js).
4. **Run**:
   ```bash
   npm run dev
   curl http://127.0.0.1:5173/healthz
   ```
5. Once it returns `ok`, **take screenshot or capture logs.**

---

## 4️⃣ Template-Specific Customization

| Template | Typical Modifications |
|-----------|----------------------|
| vite-react-canvas | Update `/src/App.tsx`, `/src/game/engine.ts` |
| nextjs-basic-ui | Add routes under `/app/api/` or components in `/app/(sections)/` |
| vanilla-ts-canvas | Edit `/src/engine.ts` and `/src/styles.css` |

---

## 5️⃣ Deployment Tips

✅ Always fix port **5173** — simplifies automation  
✅ Never delete `/healthz` files/routes  
✅ Use `npm run build && npm start` for production snapshots  
✅ Keep dependencies minimal for faster install times

## 7️⃣ Adding New Templates

To expand the library:

1. Create a new folder under `/templates/`.
2. Ensure:
   - `package.json` with `"dev"`, `"build"`, `"start"` scripts.
   - Fixed port **5173**.
   - `/healthz` endpoint.
3. Add entry in this README for documentation.
